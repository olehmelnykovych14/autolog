## 1. Вступ

### 1.1 Мета документа

Цей документ описує функціональність, можливості та вимоги до платформи **AutoLog**. Він призначений для власників автомобілів, представників автосервісів (СТО), а також усіх, хто хоче зрозуміти, що вміє цей продукт і для чого він створений.

### 1.2 Що таке AutoLog?

**AutoLog** — це безкоштовний цифровий помічник для власників автомобілів та автосервісів. Він дозволяє:

- зберігати всю сервісну історію автомобіля в одному місці
- отримувати консультації AI-механіка у будь-який час
- записуватись на СТО онлайн
- отримувати нагадування про страховку, техогляд та ТО
- ділитися звітом про стан авто з покупцем при продажі

AutoLog доступний як **веб-додаток** (з будь-якого браузера) та як **Telegram-бот** для зручності на ходу. Додаток підтримує встановлення на смартфон як PWA (без магазину застосунків).

### 1.3 Для кого цей продукт?

| Тип користувача | Хто це | Навіщо AutoLog |
|---|---|---|
| **Власник авто** | Фізична особа, яка має один або кілька автомобілів | Вести журнал, отримувати поради AI, записуватись на сервіс |
| **СТО / Партнер** | Автосервіс або механік | Отримувати записи, верифікувати ремонти, вести клієнтів |
| **Адміністратор** | Команда AutoLog | Керувати платформою |

## 2. Загальний опис системи

### 2.1 Контекст використання

AutoLog працює через інтернет. Для початку роботи потрібно:

1. Зайти на сайт AutoLog
2. Зареєструватись (email + пароль)
3. Обрати тип акаунту: **Власник авто** або **СТО**

Всі дані зберігаються у хмарі — вони доступні з будь-якого пристрою та не зникають при перевстановленні браузера.

### 2.2 Основні принципи

- **Безкоштовно** — усі функції доступні без оплати
- **Конфіденційно** — доступ до даних лише у авторизованого власника
- **Просто** — жодних технічних знань не потрібно
- **Завжди поруч** — працює через браузер та Telegram

## 7. Сценарії використання (Use Cases)

### Сценарій 1: Власник додає нове авто
1. Входить у застосунок → "Мій гараж" → "Додати автомобіль"
2. Обирає марку, модель, рік, вводить держ. номер та пробіг
3. За бажанням завантажує фото авто → "Зберегти"

### Сценарій 2: Консультація з AI-механіком
1. Переходить до розділу "AI Механік"
2. Пише: *"У моєї Toyota Camry 2018 чути скрип при гальмуванні"*
3. AI відповідає з аналізом, порадами та посиланнями на запчастини
4. Натискає "Записатись на СТО"

### Сценарій 3: СТО додає верифікований запис
1. Механік знаходить авто в AutoLog за держ. номером
2. Додає запис: "Заміна гальмівних колодок, 2 800 грн"
3. Власник бачить новий запис зі значком верифікації

### Сценарій 4: Власник продає авто
1. Переходить до деталей авто → "Сформувати звіт"
2. Отримує унікальне посилання
3. Надсилає посилання покупцю — той переглядає повну сервісну історію без реєстрації

### Сценарій 5: СТО підтверджує запис
1. Клієнт надсилає заявку через застосунок або Telegram
2. СТО бачить нову заявку → натискає "Підтвердити" або "Відхилити"
3. Клієнт отримує сповіщення про рішення

### Сценарій 6: Нагадування про закінчення страховки
1. Власник у "Налаштуваннях" додає нагадування: тип — "Страховка", дата, сповістити за 7 днів
2. О 09:00 за 7 днів Telegram-бот надсилає: *"⏰ Страховка (ОСЦПВ) — за 7 днів!"*

## 8. Обмеження та виключення

- AutoLog **не** є офіційним реєстром МТСБУ або поліції — це приватна сервісна книга
- Верифіковані записи від СТО є підтвердженням виконаних робіт, але не юридичним документом
- AI-механік надає **інформаційні** поради — він не замінює очну діагностику у сертифікованого механіка
- Для роботи Telegram-нагадувань необхідно підключити Telegram-акаунт у налаштуваннях

## 9. Глосарій

| Термін | Пояснення |
|---|---|
| **Гараж** | Особистий розділ з переліком усіх автомобілів користувача |
| **Сервісна історія** | Журнал усіх виконаних робіт та витрат по автомобілю |
| **Верифікований запис** | Сервісний запис, доданий та підтверджений офіційним СТО |
| **AI-механік** | Вбудований штучний інтелект (на базі Google Gemini) для консультацій |
| **Carfax-звіт** | PDF або публічна сторінка з повною сервісною історією авто |
| **PWA** | Progressive Web App — встановлення веб-сайту як додатку на смартфон |
| **СТО** | Станція технічного обслуговування (автосервіс) |
| **Держ. номер** | Державний реєстраційний номер автомобіля |
| **VIN** | 17-значний унікальний ідентифікаційний номер автомобіля |
| **ТО** | Технічне обслуговування (планове) |
| **ЄДРПОУ** | Ідентифікаційний код юридичної особи в Україні |
